## 🌌 Overview

**REHAAN_ENGINE Spatial Portfolio** is an interactive, continuous 3D spatial computing experience built on a 33,600m virtual coordinate Z-axis. Originally designed in Google Stitch, this production implementation elevates the design into a modular, responsive, high-performance, and accessible web application.

### Key Highlights
- **Continuous 3D Spatial Navigation**: 12 discrete spatial nodes seamlessly traversed via mouse wheel, touch drag, keyboard shortcuts, or quick teleport dots.
- **High-DPI Canvas Engine**: Dynamic multi-depth starfield and atmospheric nebular dust rendered with crisp sub-pixel precision across standard, Retina, and 4K viewports.
- **Web Audio Spatial Synth**: Movement-velocity modulated atmospheric airflow + sci-fi UI transient chirps, fully compliant with browser autoplay policies.
- **Flagship Project Showcases**: Deep-dive showcases for **MyWallpaper**, **Urban Bites**, **Falah Pro**, **FaceSense**, and **DRC Delhi**.
- **Cross-Device Fluid Ergonomics**: Responsive across mobile (320px–767px), tablet, and desktop with notch and safe-area inset protection (`env(safe-area-inset-*)`).

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: Vanilla CSS, Glassmorphism, Tailwind CSS, Responsive CSS clamp rules
- **Spatial Engine**: Custom 3D perspective matrix & inertia lerp runtime
- **Audio**: Web Audio API (real-time noise synthesis + biquad filter modulation)
- **Graphics**: Dual HTML5 2D Canvas systems with multi-depth parallax and streamer trails
- **Typography**: Space Grotesk, JetBrains Mono, Plus Jakarta Sans

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/rehaanalam0078-alm/My_Portfolio.web.git

# Navigate to project directory
cd My_Portfolio.web

# Start local server
npm start
# or
npx serve . -p 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
